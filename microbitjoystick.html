01

How it works

Before touching any code, here's the full signal path — three hops from your hand to your cursor.

Signal path

1. Sensor
Transmitter micro:bit reads its accelerometer as you tilt it.
2. Radio
Tilt values are sent wirelessly to a second micro:bit, over the built-in 2.4 GHz radio — no pairing, no Bluetooth.
3. Serial
Receiver micro:bit stays plugged into your computer and forwards every reading over USB.
4. Cursor
A small Python script reads that stream and moves your mouse to match.
info
The two boards never touch each other or your computer at the same time — only the receiver plugs in. The transmitter runs untethered, on battery or USB power bank.

03

Flash both boards

Plug in one micro:bit at a time. In Mu Editor, paste the matching code below, then click Flash. Label the boards — it's easy to mix them up later.

usb Your board — tethered

description single_board.py
from microbit import *

while True:
    x = accelerometer.get_x()
    y = accelerometer.get_y()
    z = accelerometer.get_z()

    print("{},{},{}".format(x, y, z))

    if button_a.was_pressed():
        print("CLICK_L")
    if button_b.was_pressed():
        print("CLICK_R")

    display.show(Image.ARROW_N if y < -300 else Image.ARROW_S if y > 300 else Image.SQUARE_SMALL)
    sleep(50)  # ~20Hz update rate
info
No radio needed — this board prints straight over the same USB cable that's powering it. Clicks are already built in, so you can skip step 6.

pan_tool Board 1 — Transmitter (handheld)

description transmitter.py
from microbit import *
import radio

radio.on()
radio.config(channel=7, power=7)

while True:
    x = accelerometer.get_x()
    y = accelerometer.get_y()
    z = accelerometer.get_z()

    # Pack as a simple comma-separated string
    msg = "{},{},{}".format(x, y, z)
    radio.send(msg)

    display.show(Image.ARROW_N if y < -300 else Image.ARROW_S if y > 300 else Image.SQUARE_SMALL)
    sleep(50)  # ~20Hz update rate

usb Board 2 — Receiver (stays plugged in)

description receiver.py
from microbit import *
import radio

radio.on()
radio.config(channel=7, power=7)

while True:
    msg = radio.receive()
    if msg:
        print(msg)  # goes out over USB serial
        display.show(Image.YES)
        sleep(10)
        display.clear()
priority_high
Both boards must use the same channel number. If you have neighbors also playing with micro:bits, pick a channel other than the default (0–83 are valid) so you don't cross signals.

Mouse control script

description joystick_mouse.py
import serial
import pyautogui

PORT = "/dev/tty.usbmodem14102"  # update to your receiver's port
BAUD = 115200

ser = serial.Serial(PORT, BAUD, timeout=1)
pyautogui.FAILSAFE = True  # yank mouse to top-left corner to abort

screen_w, screen_h = pyautogui.size()
cx, cy = screen_w // 2, screen_h // 2
pyautogui.moveTo(cx, cy)

SENSITIVITY = 15   # higher = faster cursor movement
DEADZONE = 60       # ignore small jitter around level

print("Tilt the transmitter to move the mouse. Ctrl+C to stop.")

while True:
    line = ser.readline().decode("utf-8", errors="ignore").strip()
    if not line:
        continue
    try:
        x, y, z = map(int, line.split(","))
    except ValueError:
        continue

    dx = 0 if abs(x) < DEADZONE else x
    dy = 0 if abs(y) < DEADZONE else y

    move_x = (dx / 1024) * SENSITIVITY
    move_y = (dy / 1024) * SENSITIVITY

    if move_x or move_y:
        pyautogui.moveRel(move_x, move_y, duration=0)
terminal shell
python joystick_mouse.py
05

Calibrate the feel

Two numbers control everything. Tune them until the cursor feels natural in your hand.

SENSITIVITY
How far the cursor moves per unit of tilt. Start at 15. Raise for a twitchier cursor, lower for finer control.
DEADZONE
How much tilt is ignored around level. Raise this if the cursor drifts when the board is resting flat.
tune
Hold the transmitter the way you actually plan to use it — flat in your palm reads differently than gripped like a remote. Calibrate in that resting position.
emergency
If the cursor ever runs away from you, slam it into a screen corner — pyautogui's failsafe will kill the script instantly.
06

Add left and right click

Buttons A and B on the transmitter become your mouse buttons. Two small additions, one on each board.

Add to transmitter.py

add append inside the while loop
if button_a.was_pressed():
    radio.send("CLICK_L")
if button_b.was_pressed():
    radio.send("CLICK_R")

Add to joystick_mouse.py

add inside the read loop
if line == "CLICK_L":
    pyautogui.click()
elif line == "CLICK_R":
    pyautogui.click(button="right")
check

Your micro:bit is a joystick.

Tilt to move, press A or B to click. Adjust SENSITIVITY and DEADZONE any time to refine the feel.
