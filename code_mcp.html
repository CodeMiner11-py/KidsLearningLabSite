CodeMCP
Local MCP server for Claude

Claude Code, but really free.

Instead of buying Claude Code, download this local MCP server so Claude can read your files, edit them, and run commands — right on your machine.

Download for Mac

Code MCP 1.0.zip · macOS only

How it works

01

Download and open the installer. It sets up a small server that runs locally on your computer.

02

Connect it to Claude. Claude talks to the server over MCP — nothing leaves your machine except what you ask it to touch.

03

Ask Claude to work on your project. It can read files, make edits, and run commands, just like Claude Code.

Not affiliated with Anthropic. Just a local MCP server.
